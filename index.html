Algorithm guide
What happens behind the scenes

      

        
01
Bubble Sort
Repeatedly swaps neighboring values that are out of order.
Average: O(n²)

        
02
Selection Sort
Finds the smallest remaining value and moves it into place.
Average: O(n²)

        
03
Insertion Sort
Inserts each value into the correct position in the sorted section.
Average: O(n²)

        
04
Merge Sort
Splits the list, sorts each half, then merges them together.
Average: O(n log n)

        
05
Quick Sort
Uses a pivot to partition smaller and larger values.
Average: O(n log n)
